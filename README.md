# MyPersonalAssistent

Android-приложение для создания и настройки чат-ассистентов по модели и API-ключу.
Application ID / namespace: `com.mypersonalassistent`, minSdk 26.
MVP: текстовый чат, тестирование на DeepSeek API.
Сейчас подготовлены правила разработки и процесс. Первое задание на разработку
заказчик поставит в следующей сессии; Android-каркас пока не создаётся.

- [Правила для каждой сессии](AGENTS.md)
- [Обязательный стек и архитектура](docs/INVARIANTS.md)
- [Этапы и команды управления задачами](docs/WORKFLOW.md)
- [Android-разработчик](docs/agents/android-developer.md)
- [Мобильный тестировщик](docs/agents/mobile-qa.md)
- [Системный аналитик](docs/agents/system-analyst.md)
- [Код-ревьюер](docs/agents/code-reviewer.md)
- [Вопросы для старта](docs/OPEN-QUESTIONS.md)
- [Реестр зависимостей](docs/DEPENDENCIES.md)

В новой сессии открывай эту папку проекта. AGENTS.md служит автоматически читаемой
точкой входа Codex и направляет к остальным файлам. Профили — инструкции ролей;
они не регистрируют отдельные процессы или инструменты агентов в интерфейсе.
Для продолжения укажи ID задачи; состояние и результаты находятся в tasks/<ID>.
Файлы следует хранить вместе с исходниками в Git, чтобы переносить правила на другие машины.

Сабагенты запускаются с явными параметрами: кодер и QA — `gpt-5.6-terra` / `high`,
аналитик и код-ревьюер — `gpt-5.6-sol` / `medium`. Наследование модели запрещено.

Документация механизма:
[AGENTS.md](https://developers.openai.com/es-419/docs/agent-configuration/agents-md).
