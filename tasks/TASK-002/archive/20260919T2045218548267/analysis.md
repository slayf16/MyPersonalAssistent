Критерии приёмки (черновик):
- AC1: без ключа открывается форма ввода, после успешного защищённого сохранения — главная; при ошибке записи перехода нет.
- AC2: при отсутствии сохранённых чатов виден точный пустой текст; FAB открывает новый чат без записи в Room.
- AC3: сохранённые темы отображаются в LazyColumn; нажатие открывает контекст выбранного ID.
- AC4: сообщения различаются по роли, поле ввода закреплено снизу; пустую отправку и повторное параллельное нажатие блокируем.
- AC5: системный Back и стрелка вызывают одинаковую модалку; «Да» атомарно сохраняет и выходит, ошибка оставляет чат открытым; «Нет» не сохраняет текущую сессию. Прежняя версия остаётся неизменной.
- AC6: до выбора «Да» история в БД не меняется; повторное сохранение обновляет тот же ID.
- AC7: ключ не хранится открытым текстом, не попадает в логи/backup; ошибка расшифровки возвращает ввод ключа без удаления истории.
- AC8: реальный DeepSeek вызывается через Llm.execute, заменяемый через DI; ошибка и повтор не создают дубль сообщения, отмена не отображается как ошибка.
