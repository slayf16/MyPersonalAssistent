# TASK-002: проверка LLM на моках

Дата: 2026-09-20. Прямое решение заказчика: «тестируй на моках , дипсик потом сам подключу проверю».

Настоящий DeepSeek adapter и ввод/защита ключа остаются в приложении. Приёмочные сетевые проверки выполняются через fake Llm и Ktor MockEngine; реальный сетевой smoke выполняет заказчик позднее самостоятельно. Live smoke имеет N/A по решению пользователя и не блокирует DONE. Ключ не требуется и не запрашивается в чате. Позднее явное решение заменяет соответствующую строку тестовой матрицы утверждённого specs.md; функциональный scope и лимит циклов не меняются.
