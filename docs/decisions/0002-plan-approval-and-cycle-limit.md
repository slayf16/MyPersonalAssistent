# 0002 — Аппрув плана и два цикла разработки

Дата: 2026-09-19. Источник: явное поручение заказчика добавить аппрув плана,
лимит двух циклов и остановку для решения о дополнительных циклах, ручном исправлении
или принятии результата с коммитом.

План утверждается до CODING; аппрув привязан к содержимому specs.md.
Цикл считается при входе в CODING, даже если его проверки закончились раньше TESTING.
По исчерпании лимита дополнительные изменения требуют решения заказчика.
Успешный первый/второй цикл завершается без дополнительного аппрува результата.
Принятие известных проблем имеет отдельный статус ACCEPTED_WITH_ISSUES.
Коммит и push выполняются по поручению пользователя.

Текущая правка процесса прямо поручена вместе с amend и force push; повторное
согласование этой конкретной настройки не требуется. Новые задачи следуют новому порядку.
