# Матрица устройств TASK-002: только target SDK

Дата: 2026-09-19. Прямое решение заказчика в текущем диалоге: «забей хуй на 26 проверяй только на таргете».

Отменена подготовка/проверка на API26. Фактические Android UI/instrumentation проверки выполняются только на API, равном targetSdk приложения. minSdk26 не меняется. Проверки API26 имеют N/A по решению заказчика, а не PASS/BLOCKED. Это явное сужение тестовой матрицы утверждённого плана; функциональный scope и лимит циклов не меняются. Исполнители уведомлены. Приоритет этого более позднего решения выше старого перечисления устройств в specs.md; hash утверждённой спецификации сохраняется для аудита.
